    journey

    I wanted an experiment first for faster rendering stack with text support.

    1. 2016first bars, drawn for wavearea: audio edited in a textarea
    2. 2021variable width; linefont, for lines
    3. 2022three axes: weight, roundness, alignment
    4. 2023on Google Fonts
    5. 2026bars by range, one character each: 60 fps

    <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Wavefont:ROND,YELA,wght@0..100,-100..100,4..1000&display=block">

el.textContent = bars(lo, hi) // level ranges
